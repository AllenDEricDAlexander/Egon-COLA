# Egon-COLA Light Archetype

This classifier documents the Egon-COLA Light Maven Archetype distribution. It is documentation for the archetype, not a Java API reference.

Use the public `top.egon:egon-cola-archetype-light` coordinate with Maven's `archetype:generate` goal to create a project. Maintainers edit the corresponding normal source project under `source-projects`, then run `scripts/generate_archetypes.sh generate` before packaging.
